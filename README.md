# Peyton Webster — AI Builder Portfolio

A static portfolio presenting AI workflow, enterprise implementation, agentic experimentation, and AI-adoption case studies.

## Local preview

```bash
python3 -m http.server 5173 --directory public
```

Then open [http://127.0.0.1:5173](http://127.0.0.1:5173).

## Contents

- **ClinTranslate AI** — a multimodal workflow that turns messy clinical source material into implementation-ready requirements.
- **AMEND Flow** — an agentic resolution-workflow prototype for cross-team operational signals.
- **Live Decision Lab** — a live Manus decision-support experience built for Austin Tech Week.
- **Manus Events** — hands-on product-adoption events and community learning.
- **Market Technology Workspace** — an AI-assisted intake and technical-routing prototype.

The ClinTranslate demo included in `public/assets/` is the sanitized, output-preserving public version.
